# 快速复制助手（Chrome 插件）

在网页中给指定类名的输入框下方加一个「快速复制」按钮，点击后把该输入框的内容自动填入你指定的另一个输入框，同时写入剪贴板。

## 功能

- **按类名识别输入框**：给每条规则填写一个类名（也支持任意 CSS 选择器），插件会在页面中匹配到的输入框下方悬浮显示「快速复制」按钮。
- **todolist 式弹窗管理**：点击工具栏图标弹出列表，可随时添加、删除、启用/停用规则，修改自动保存。
- **目标拾取**：不方便写选择器时，点规则右侧的「拾取」，再直接到页面上点一下目标输入框即可。
- **兼容动态页面**：页面延迟渲染、SPA 切换、动态新增的输入框也能自动识别。
- **兼容前端框架**：填入时会触发 `input` / `change` 事件，React / Vue 等受控输入框也能同步状态。
- **即点即用**：填入目标输入框后还会自动写入系统剪贴板（网站不允许时会自动降级）。

## 安装

1. 打开 Chrome，地址栏输入 `chrome://extensions/`。
2. 打开右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本项目文件夹（包含 `manifest.json` 的目录）。
4. 建议把插件固定到工具栏，方便随时打开列表。

## 使用

1. 打开要使用的网页。
2. 点击插件图标，在弹窗中填写：
   - **源类名**：例如输入框是 `<input class="price-input">`，就填 `price-input`。
   - **目标选择器**：想填入的目标输入框，例如 `<input id="remark">` 就填 `#remark`；也可以点「拾取」到页面上直接点选。
3. 点「＋ 添加规则」。
4. 回到网页，源输入框下方会出现「快速复制」按钮，点击即可把内容填到目标输入框。

### 选择器写法说明

| 填写内容 | 含义 |
| --- | --- |
| `price-input` | 纯类名，匹配 `input.price-input` 和 `textarea.price-input`（推荐） |
| `.price-input` | CSS 类选择器 |
| `#remark` | id 选择器 |
| `form .row input[type="text"]` | 任意 CSS 选择器 |
| `input[name="price"]` | 属性选择器 |

- 一个类名建议单独一条规则；源输入框同时匹配多条规则时，按列表顺序取第一条。
- 目标选择器匹配到多个元素时，优先使用第一个可见的输入框；也可以直接填包裹输入框的容器选择器，插件会自动找里面的输入框。
- 目标输入框为空时，点击按钮会提示「未找到目标输入框」。

## 测试

打开 `demo/test.html`，按页面中的提示添加规则即可验证：

- 示例 1：源 `price-input` → 目标 `#remark`
- 示例 2：源 `dynamic-input` → 目标 `#dynamic-target`

> 直接双击以 `file://` 打开测试页时，需要在 `chrome://extensions/` 的插件详情里开启「允许访问文件网址」，插件才能在本地文件页面生效；也可以在本目录执行 `python -m http.server 8000`，然后访问 `http://localhost:8000/demo/test.html`（推荐）。

## 说明与限制

- 不作用于 `chrome://` 页面、Chrome 应用商店等浏览器内置页面。
- 页面中的 `iframe` 内部输入框暂不支持（插件只注入顶层页面）。
- 如果网页使用了封闭的 Shadow DOM，插件无法匹配其中的输入框。
- 安装插件前已经打开的页面，需要刷新一次才会出现按钮。
- 规则保存在 `chrome.storage.sync`，登录同一 Chrome 账号的浏览器之间会自动同步。

## 文件结构

```
manifest.json     扩展清单（Manifest V3）
content.js        内容脚本：匹配输入框、注入按钮、执行复制、目标拾取
popup.html        弹窗界面
popup.css         弹窗样式
popup.js          弹窗逻辑：规则增删改、拾取入口、匹配数量展示
demo/test.html    本地测试页
```
